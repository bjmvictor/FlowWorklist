# FlowWorklist documentation

FlowWorklist provides DICOM MWL, optional MPPS processing and actions, optional DICOM Print, and a management interface.

Start with:

1. [README](https://github.com/bjmvictor/FlowWorklist/blob/main/README.md) for installation and basic configuration.
2. [Architecture](https://github.com/bjmvictor/FlowWorklist/wiki/Architecture) for the MWL-to-MPPS workflow.
3. [Production Deployment](https://github.com/bjmvictor/FlowWorklist/blob/main/docs/DEPLOYMENT.md) for supervised operation.
4. [Validation](https://github.com/bjmvictor/FlowWorklist/wiki/Validation) before go-live.

The complete topic map is in the [documentation index](https://github.com/bjmvictor/FlowWorklist/blob/main/docs/INDEX.md). Canonical documents contain the full instructions; wiki pages stay intentionally concise to avoid duplication.
